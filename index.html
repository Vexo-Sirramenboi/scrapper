GameHub

Auto-finder + link checker. Discovers links from GitHub, scrapes any page, searches the web (DDG/Bing/Google), finds web proxies, and probes everything from your network — with HTTPS & tracker info per link.

How it works / limits
ContentKeeper and Umbrella filter at the network level, so this page can't change what's blocked — but it can find and test links for you. Red usually means the proxy reset the connection (blocked); yellow means the site answered but looks like a block page — open it manually.

• Search web — tries DuckDuckGo, then Bing (RSS), then Google, through CORS proxies. Search engines actively block browser scrapers, so this often fails or returns little — expected, not a bug. GitHub Discover and page Scrape are the reliable paths.
• Find proxies — searches GitHub repos + the web, keeps links with "proxy" in the hostname/path, checks them like any link. Heuristic — it'll miss some and catch some junk; add known proxies manually.
• GitHub API limits: ~10 searches/min, 60 core requests/hr without a token — don't spam Discover/Find proxies.
• Google hosts (sites.google.com, drive.google.com, docs.google.com, googleusercontent.com) are pre-blocked for you: skipped during discovery and marked "blocked by school" instantly. Add more to CONFIG.blockedHosts.
• Security line — HTTPS vs HTTP — not secure, plus a best-effort tracker scan. privacy scan failed means the CORS proxies were unreachable. "URL shortener" means the link redirects somewhere unknown.
• Reality check: your school runs ContentKeeper, which TLS-inspects HTTPS anyway — "secure" doesn't mean private from the school. And check your school's acceptable-use policy before relying on this.
