GameHub

Auto-finder + link checker, 100% static (works on managed Chromebooks). Discovers links from GitHub, scrapes any page, searches the web (Bing RSS, DuckDuckGo, Wikipedia, Google), finds web proxies, and probes everything from your network — with HTTPS & tracker info per link.

How it works / limits
ContentKeeper/Umbrella filter at the network level — this page can't unblock anything, but it can find and test links for you. Red = blocked or down; yellow = answers but looks like a block page; green = reachable now.

• Fetching order — direct (for CORS-open sites like Wikipedia) → r.jina.ai (free page-to-text reader, keyless) → api.allorigins.win → corsproxy.io → api.codetabs.com. Public proxies rotate and die constantly — if everything's failing, swap in new ones at CONFIG.fetchProxies.
• Search web — Bing RSS, then DuckDuckGo, then Wikipedia (reliable, direct CORS), then Google (usually blocked by anti-bot — expected). Search engines fight scrapers; "no results" sometimes just means "try again later."
• Find proxies — GitHub repos + web search, keeping links with "proxy" in the host/path. Heuristic — it misses some and catches junk; add known proxies manually.
• Tracker scan caveat — if a page was fetched through r.jina.ai (markdown), the script/tracker count can under-report, because scripts are stripped before you see the text.
• Google hosts (sites.google.com, drive.google.com, docs.google.com, googleusercontent.com) are pre-blocked for you — add more to CONFIG.blockedHosts.
• GitHub API — ~10 searches/min, 60 core requests/hr unauthenticated; don't spam Discover.
• If the filter blocks github.io itself, this page won't load. Use Export/Import to move your list between home and school. Check your school's acceptable-use policy before relying on this.
