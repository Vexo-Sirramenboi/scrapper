GameHub

Auto-finder + link checker. It discovers game links from GitHub repos, scrapes links from any page you paste, and probes everything from your network — with security & privacy info per link.

How it works / limits
ContentKeeper and Umbrella filter at the network level, so this page can't change what's blocked — but it can find and test links for you. With ContentKeeper, red usually means the proxy reset the connection (blocked); yellow means the site answered but looks like a block page — open it manually to confirm.

• Discover uses the GitHub search API — rate-limited (~10 searches/min, 60 core calls/hr without login), and api.github.com can itself be blocked.
• Scrape routes through public CORS proxies, which get blocked or rate-limited often. If it fails, add another proxy to CONFIG.proxies.
• Google hosts (sites.google.com, drive.google.com, docs.google.com, googleusercontent.com) are pre-blocked for you: skipped during Discover/Scrape and marked "blocked by school" instantly. Add more to CONFIG.blockedHosts as you find them.
• Security line on each card — instant: HTTPS (encrypted in transit) vs HTTP — not secure (plain, snoopable). Then a best-effort tracker scan: counts ad/analytics scripts found in the page HTML. privacy scan failed means the CORS proxies were unreachable. A "URL shortener" flag means the link redirects somewhere unknown — extra caution.
• Reality check: your school runs ContentKeeper, which TLS-inspects HTTPS anyway. "Secure" here means encrypted to your browser's ability — not private from the school. And a privacy-friendly site with zero trackers is exactly the kind of small page that's most likely to actually be unblocked.
• Links are saved in your browser only — use Export/Import to share your list with friends. Check your school's acceptable-use policy before relying on this.
